# 토마토(도장) 보내기

흐름: **친구 선택 → 메시지 작성 → 꾹 눌러서 도장찍기 → 도장 전송 완료 → 홈으로**
Figma 섹션: 회원 홈 > 친구 선택 / 토마토 보내기, 비회원 홈 > 토마토 보내기
진입점: 홈, 친구 목록(F-52), 친구 칭찬판(F-54), 비회원 홈.

| ID   | 기능               | 설명                                                                                                                             |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| F-20 | 친구 선택          | `친구 이름 검색` 입력 + 친구 목록 격자. 선택 시 체크 표시, `메세지 작성`.                                                        |
| F-21 | 메시지 작성        | "어떤 점이 좋은가요?" 키워드 칩(다정해요, 재미있어요, 믿음직해요, 센스있어요, 멋있어요 …) + "직접 한 마디 남기기" 텍스트(0/200). |
| F-22 | 도장 찍기          | "꾹 눌러서 도장찍기" 롱프레스 인터랙션. To(받는 친구), 날짜 표시.                                                                |
| F-23 | 전송 완료          | "도장을 전달 완료했어요!" + `홈으로`.                                                                                            |
| F-24 | 비회원 도장 보내기 | 회원 흐름과 동일하되 친구 선택 대신 받는 사람의 칭찬판("민준's Tomato")에서 시작. 전송 후 `내 칭찬판 만들기`(= 회원가입) 유도.   |

## AC

- 메시지는 최대 200자(`0/200` 카운터).
- 키워드 또는 직접 메시지 중 하나는 있어야 `도장찍기`로 진행 가능 (확인 필요).
- 도장은 롱프레스 완료 시에만 전송된다.
- 전송 완료 후 받는 사람에게 푸시 알림이 간다 ([notifications.md](notifications.md) F-60).
- 비회원 전송 완료 화면에서 `내 칭찬판 만들기`는 회원가입으로 이동한다.
