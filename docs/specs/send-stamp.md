# 토마토(도장) 보내기

흐름(회원): **홈 `+` 버튼 → 친구 선택 → 메시지 작성 + 꾹 눌러서 토마토찍기 → `다음`(전송) → 전달 완료 → `확인` → 홈**
흐름(비회원): **공유 링크 → 메시지 작성 + 꾹 눌러서 토마토찍기 → `다음`(전송) → 전달 완료 → `확인` → 비회원 홈**
Figma 섹션: "10/26" > 회원 홈 > 친구 선택 / 토마토 보내기, 비회원 홈 > 토마토 보내기
진입점: 홈 `+` 버튼, 친구 목록(F-52), 친구 칭찬판(F-54), 공유 링크(비회원).

| ID   | 기능               | 설명                                                                                                                                                                                   |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-20 | 친구 선택          | 홈 위에 뜨는 바텀시트("친구"). `친구 이름 검색` 입력 + 친구 목록 격자(프로필 + 이름). 선택 시 체크 표시, 하단 `메세지 작성` 버튼. `X`로 닫기.                                           |
| F-21 | 메시지 작성        | 상단 `<` 뒤로가기, `🍅 To {친구 이름}`. "어떤 점이 좋은가요?" 키워드 칩(다정해요, 재미있어요, 믿음직해요, 센스있어요, 멋있어요 …, 다중 선택) + "칭찬 한 마디를 직접 남겨보세요! (선택)" 텍스트(글자 수 카운터). 하단 `꾹 눌러서 토마토찍기` 버튼. |
| F-22 | 토마토 찍기        | F-21과 같은 화면. `꾹 눌러서 토마토찍기` 롱프레스 완료 시 메시지 위에 토마토 도장이 찍히고, 하단 버튼이 `다음`으로 바뀐다. `다음`을 누르면 전송된다.                                     |
| F-23 | 전달 완료          | "토마토를 전달했어요!" + 보낸 도장 카드(날짜, To, 키워드 칩, 메시지) + `확인`. `확인` 시 홈으로 이동.                                                                                   |
| F-24 | 비회원 도장 보내기 | 공유 링크로 진입하면 친구 선택 없이 바로 메시지 작성(F-21)부터 시작. To는 링크를 공유한 회원. 이후 F-22~F-23과 동일하며 `확인` 시 비회원 홈(`내 칭찬판 만들기`)으로 이동.                  |

## AC

- 친구를 선택해야 `메세지 작성`으로 진행할 수 있다.
- 메시지 작성 화면에 받는 사람 이름이 `To`로 표시된다.
- 키워드 칩은 여러 개 선택할 수 있다.
- 키워드와 직접 메시지는 모두 선택 입력이다 (키워드 필수 여부 **[논의 필요]**).
- 롱프레스를 끝까지 완료해야 토마토가 찍히고 `다음`이 나타난다.
- 도장은 `다음`을 누른 시점에 전송된다.
- 전달 완료 화면에 보낸 도장의 날짜, 받는 사람, 키워드, 메시지가 표시된다.
- 회원은 `확인` 시 회원 홈(F-10), 비회원은 비회원 홈으로 이동한다.
- 전송 완료 후 받는 사람에게 푸시 알림이 간다 ([notifications.md](notifications.md) F-60).
- 비회원 홈의 `내 칭찬판 만들기`는 회원가입으로 이동한다.

## Open Questions

- **[논의 필요]** 키워드 필수 여부. 현재는 필수 아님. 키워드와 메시지가 모두 선택이면 빈 토마토 전송이 가능해짐.
- **[논의 필요]** 토마토를 찍은 뒤(`다음` 전) `<` 뒤로가기나 칩·메시지 수정 허용 여부.
- **[논의 필요]** 키워드 다중 선택 시 최대 개수.
- **[논의 필요]** 메시지 최대 글자 수. Figma의 `0/200`은 임시 값.
- **[논의 필요]** 친구 단일/다중 선택(한 번에 여러 친구에게 보내기 가능 여부). Figma에는 1명 선택만 있음.
- **[논의 필요]** 비회원 → 회원 전환 시 비회원으로 보낸 도장 처리.
- **[논의 필요]** 키워드 칩 목록 확정. Figma에 `다정해요`가 중복 노출됨.
