# 토마토(도장) 보내기

흐름(회원): **홈 `+` 버튼 → 친구 선택 → 메시지 작성 + 꾹 눌러서 토마토찍기 → `편지 보내기`(전송) → 전달 완료 → `확인` → 홈**
흐름(비회원): **공유 링크 → 메시지 작성 + 꾹 눌러서 토마토찍기 → `편지 보내기`(전송) → 전달 완료 → `확인` → 받는 사람의 토마토 박스**
Figma 섹션: "11/02" > 회원 홈 > 친구 선택 / 토마토 보내기, 비회원 홈 > 토마토 보내기
진입점: 홈 `+` 버튼, 친구 목록(F-52), 친구 칭찬판(F-54), 공유 링크(비회원).

| ID   | 기능               | 설명                                                                                                                                                                                   |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-20 | 친구 선택          | 홈 위에 뜨는 바텀시트("친구"). `친구 이름 검색` 입력 + 친구 목록 격자(프로필 + 이름). 선택 시 체크 표시, 하단 `메시지 작성` 버튼. `X`로 닫기.                                           |
| F-21 | 메시지 작성        | 상단 `<` 뒤로가기, `🍅 To {친구 이름}`. "어떤 점이 좋은가요?" 키워드 칩 10개(다정해요, 재미있어요, 믿음직해요, 따뜻해요, 공감을 잘해요, 센스있어요, 멋있어요, 꾸준해요, 생각이 깊어요, 귀여워요, 다중 선택) + "칭찬 한 마디를 직접 남겨보세요! (선택)" 텍스트(글자 수 카운터). 하단 `꾹 눌러서 토마토찍기` 버튼. |
| F-22 | 토마토 찍기        | F-21과 같은 화면. `꾹 눌러서 토마토찍기` 롱프레스 완료 시 메시지 위에 토마토 도장이 찍히고, 하단 버튼이 `편지 보내기`로 바뀐다. `편지 보내기`를 누르면 전송된다.                                     |
| F-23 | 전달 완료          | "토마토를 전달했어요!" + 보낸 도장 카드(날짜, To, 키워드 칩, 메시지) + `확인`. `확인` 시 홈으로 이동.                                                                                   |
| F-24 | 비회원 도장 보내기 | 공유 링크로 진입하면 친구 선택 없이 바로 메시지 작성(F-21)부터 시작. To는 링크를 공유한 회원. 이후 F-22~F-23과 동일하며 `확인` 시 받는 사람의 토마토 박스("{받는 사람}의 10월 토마토 {개수}" + `내 칭찬판 만들기`)로 이동.                  |

## AC

- (회원) 홈 `+`로 진입하면 친구를 선택해야 `메시지 작성`으로 진행할 수 있다. 친구 목록의 `토마토 보내기`([friends.md](friends.md) F-52)와 친구 칭찬판의 도장찍기(F-54)는 친구 선택 없이 메시지 작성부터 시작한다.
- 비회원은 친구 선택 없이 메시지 작성부터 시작한다(F-24). 이후 화면은 회원과 동일하다(칩 10개, `꾹 눌러서 토마토찍기` → `편지 보내기`). Figma의 비회원 화면은 이전 디자인(`다음`, 칩 6개)이라 업데이트가 필요하다.
- 메시지 작성 화면에 받는 사람 이름이 `To`로 표시된다.
- 키워드 칩은 개수 제한 없이 여러 개 선택할 수 있다.
- 메시지 최대 글자 수는 구현 시 정한다. Figma의 `0/200`은 임시 값이다.
- 키워드와 직접 메시지 중 하나 이상은 있어야 한다. 키워드를 하나도 선택하지 않으면 직접 메시지는 필수다.
- 키워드도 메시지도 없으면 `꾹 눌러서 토마토찍기` 버튼이 비활성화된다. 칩을 선택하거나 메시지를 입력하면 활성화된다.
- 롱프레스를 끝까지 완료해야 토마토가 찍히고 `편지 보내기`가 나타난다.
- 토마토를 찍은 뒤에는 칩과 메시지를 수정할 수 없다. `<`를 누르면 도장이 취소되어 작성 상태로 돌아가고, 입력한 칩과 메시지는 유지된다.
- 도장은 `편지 보내기`를 누른 시점에 전송된다.
- 전달 완료 화면에 보낸 도장의 날짜, 받는 사람, 키워드, 메시지가 표시된다.
- 회원은 `확인` 시 회원 홈(F-10), 비회원은 받는 사람의 토마토 박스로 이동한다.
- 전송 완료 후 받는 사람에게 푸시 알림이 간다 ([notifications.md](notifications.md) F-60).
- 비회원 화면의 `내 칭찬판 만들기`는 회원가입/로그인 선택 화면으로 이동한다.
- 비회원으로 보낸 도장은 받는 사람에게 그대로 남고, 보낸 사람이 나중에 가입해도 그 계정의 보낸 기록에는 연결하지 않는다.
