## 제품 개요

- **멋토 (Meotto)**: 말로 전하기 쑥스러운 칭찬을 **토마토 도장**에 담아 친구에게 보내는 앱. 친구들에게 받은 토마토는 **칭찬판**에 모여, 친구들이 발견한 나의 칭찬을 확인할 수 있다.
- 슬로건: "토마토 도장으로 전하는 마음"
- 핵심 경험 (온보딩 3장 순서, 카피 원문은 [auth-onboarding.md](auth-onboarding.md)):
  1. 친구의 멋 발견하기
  2. 토마토 도장으로 마음 전하기
  3. 친구들이 발견한 나의 칭찬 모아보기
- 하단 탭 3개: **Home**([home.md](home.md)) / **My**([my-board.md](my-board.md)) / **Friend**([friends.md](friends.md)).
- 플랫폼: 회원은 모바일 앱. 비회원은 칭찬 요청 공유 링크로 들어와 앱 설치 없이 웹(`frontend/apps/web`)에서 보낸다.
- **[논의 필요]** 비회원이 `내 칭찬판 만들기`를 누른 뒤 소셜 로그인을 웹에서 할지, 앱 설치로 보낼지.
- 사용자 유형: **회원**, **비회원**(친구가 공유한 칭찬 요청 링크로 들어와 도장 보내기 가능).

## 용어

- **멋토**: 앱 이름이자, 주고받는 토마토 도장을 부르는 말("멋토를 보내볼까요?", "받은 멋토").
- **편지**: 키워드 또는 직접 메시지(하나 이상)를 담아 토마토 도장과 함께 보내는 것. 보내기 버튼 문구는 `편지 보내기`.
- **도장(스탬프)**: 친구가 보내는 토마토 모양 칭찬 단위. 키워드 또는 직접 메시지(하나 이상)를 담는다.
- **토마토**: 도장과 같은 의미로 UI에서 혼용("토마토 보내기", "받은 토마토").
- **칭찬판**: 받은 도장이 격자로 쌓이는 개인 보드. My 탭 화면이며 UI·IA의 "칭찬도장", "도장판"과 같은 것.
- **도장찍기**: ① 홈의 `+` 버튼으로 시작하는 보내기 흐름, ② 메시지 작성 화면의 "꾹 눌러서 토마토찍기" 롱프레스. 두 의미를 구분한다.
- **뱃지**: 도장 획득에 따라 모이는 컬렉션 아이템(케찹, 파스타 등).

## IA (정보 구조)

```
멋토
└─ 온보딩 (3장 + 시작 화면)
   ├─ 소셜 로그인
   │   ├─ 홈
   │   │   ├─ 뉴 도장 ┐
   │   │   └─ 기존 도장 ┴→ 새로 받은 도장 → [+ 버튼] → 친구선택 → 메시지 작성 + 꾹 눌러 토마토찍기 → 편지 보내기(전송) → 전달 완료 → 홈
   │   ├─ 내 칭찬판 (My)
   │   │   ├─ 받은 도장 / 뱃지 컬렉션 / 많이 받은 칭찬 / 주고 받은 토마토
   │   │   └─ 마이페이지
   │   │       ├─ 내 프로필
   │   │       ├─ 칭찬판 공유하기 → QR코드 / 링크 주소 / SNS 공유
   │   │       ├─ 서비스 설정 → 알림 / 칭찬판 공개 여부
   │   │       ├─ 로그아웃
   │   │       └─ 회원탈퇴
   │   └─ 친구 (Friend)
   │       └─ 검색 → 친구 추가 → 친구 목록 → 친구 칭찬판 → 친구 도장찍기
   └─ 칭찬 요청 공유 링크로 비회원 진입
       └─ 비회원 홈(토마토 보내기 화면): 메시지 작성 + 꾹 눌러 토마토찍기 → 편지 보내기(전송) → 전달 완료 → 받는 사람의 토마토 박스
           └─ 내 칭찬판 만들기 → 소셜 로그인
```

## 작성 규칙

- 기능마다 고유 ID(`F-xx`)와 검증 가능한 인수 조건(AC).
- 커밋/PR에서 기능 ID를 참조한다.
- 범위 밖과 Open Questions는 해당 기능 파일 안에 둔다.
- 미확정 항목은 반드시 **[논의 필요]** 태그를 붙여 함께 작업하는 사람이 찾아서 논의할 수 있게 한다.
- 백엔드 API, 데이터 모델, 인증 방식 상세는 이 문서 범위 밖.
