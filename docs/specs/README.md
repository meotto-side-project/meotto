## 제품 개요

- **멋토 (Meotto)**: 친구에게 **토마토 도장**에 마음(칭찬)을 담아 보내고, 받은 도장을 **칭찬판**에 모아 "나의 멋"을 발견하는 모바일 앱.
- 핵심 카피: "친구의 멋을 발견해봐요!", "토마토 도장에 마음을 담아 친구에게 전달해보세요!", "친구들이 발견한 나의 멋"
- 플랫폼: 모바일(iPhone 17 프레임 402×874). 하단 탭 3개: **Home / My / Friend**.
- 사용자 유형: **회원**, **비회원**(공유받은 칭찬판에서 도장 보내기 가능).

## 용어

- **도장(스탬프)**: 친구가 보내는 토마토 모양 칭찬 단위. 키워드 + 메시지를 담는다.
- **토마토**: 도장과 같은 의미로 UI에서 혼용("토마토 보내기", "받은 토마토").
- **칭찬판**: 받은 도장이 격자로 쌓이는 개인 보드.
- **뱃지**: 도장 획득에 따라 모이는 컬렉션 아이템(케찹, 파스타 등).

## IA (정보 구조)

```
멋토
└─ 온보딩 (3장 + 시작 화면)
   ├─ 회원가입 → 로그인
   │   ├─ 홈
   │   │   ├─ 뉴 도장 ┐
   │   │   └─ 기존 도장 ┴→ 새로 받은 도장 → 도장찍기 → 친구선택 → 메시지 작성 → 도장전송
   │   ├─ 칭찬도장 (My)
   │   │   ├─ 받은 도장 / 뱃지 컬렉션 / 많이 받은 칭찬 / 주고 받은 토마토
   │   │   └─ 마이페이지
   │   │       ├─ 내 프로필
   │   │       ├─ 칭찬판 공유하기 → QR코드 / 링크 주소 / SNS 공유
   │   │       ├─ 서비스 설정 → 알림 / 칭찬판 공개 여부
   │   │       ├─ 로그아웃
   │   │       └─ 회원탈퇴
   │   └─ 친구 (Friend)
   │       └─ 검색 → 친구 추가 → 친구 목록 → 친구 칭찬판 → 친구 도장찍기
   └─ 비회원 로그인
       └─ 홈 (비회원)
           ├─ 도장찍기 → 메시지 작성 → 도장전송
           └─ 내 도장판 만들기 → 회원가입
```

## 작성 규칙

- 기능마다 고유 ID(`F-xx`)와 검증 가능한 인수 조건(AC).
- 커밋/PR에서 기능 ID를 참조한다.
- 범위 밖과 Open Questions는 해당 기능 파일 안에 둔다.
- 백엔드 API, 데이터 모델, 인증 방식 상세는 이 문서 범위 밖.
