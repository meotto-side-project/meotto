# 디자인 시스템

Figma 섹션: 디자인시스템 (노드 `7615:5286` 내부)
정확한 토큰 값은 구현 시점에 Figma `get_variable_defs` 또는 디자인시스템 섹션 `get_design_context`로 추출한다. 이 문서는 요약만 담는다.

## 색상

하늘색(파란 도장/포인트), 토마토 레드, 그린(꼭지), 다크 레드, 베이지 + 그레이/블랙 스케일. 로고는 흰/검정 배경 2종.

## 반경

50px / 30px / 10px.

## 타이포

Heading(H1 등, 예 20px / 30% / -1%, 16px / 30% / -1%), Title, Body, Button, Label, Caption. 영문/로고/한글 모두 Poppins 지정(한글 텍스트 샘플은 Figma에 없음).

## 공통 컴포넌트

- 하단 탭바: Home / My / Friend, 다크 필 + 선택 탭 라이트 필.
- 버튼: 다크 필.
- 키워드 칩, 토글, 아바타 + 라벨 리스트 행, 뱃지 아이콘 타일.
- 모달.

## Open Questions

- 검색 입력창, 메시지 작성 텍스트 영역(0/200 카운터), QR 코드, 온보딩 슬라이드 인디케이터 등 다른 스펙 파일에 등장하는 컴포넌트들의 디자인시스템 반영 여부. (전송완료 등 오버레이는 `모달` 컴포넌트로 확인됨.)
- 온보딩 마지막 장("어두운 시작 화면", [auth-onboarding.md](auth-onboarding.md) F-02) 배경이 전용 다크 서피스 토큰이 아닌 `Labels/Primary`(라벨 색상) 변수를 재사용 중. 의도적인지 확인 필요.
- Poppins는 한글 글리프를 지원하지 않는 폰트라, 한글에도 Poppins로 지정돼 있다면 실제 렌더링 시 폴백 폰트가 적용될 가능성. 한글 샘플 텍스트로 재확인 필요.
