# 스플래시 · 온보딩 · 인증

IA: 멋토 → 온보딩 → 소셜 로그인 → 홈 | (칭찬 요청 공유 링크로 비회원 진입 → 토마토 보내기 → 비회원 홈)
Figma 섹션: 스플래시, 온보딩, 로그인

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 스플래시 | 흰 배경에 Meotto 로고. 앱 진입 시 노출 후 온보딩 또는 홈으로 이동. |
| F-02 | 온보딩 | 3장 슬라이드(하단 인디케이터 도트 3개). 하단 `다음` 버튼, 마지막 장은 `멋토 시작하기`. `멋토 시작하기`를 누르면 로그인 화면(F-03)으로 이동. |
| F-03 | 소셜 로그인 | 로그인 화면: Meotto 로고 + `카카오톡으로 시작하기`, `네이버로 시작하기`, `Apple로 시작하기` 3개 버튼. 소셜 로그인으로 가입·로그인을 동시에 처리하며 `회원가입`/`로그인` 버튼은 따로 없다. 처음 가입하는 경우 프로필 입력(닉네임, 아이디, 프로필 사진(선택))을 거친다. 아이디는 `@{아이디}` 형태이며, `{아이디}`는 백엔드에서 랜덤으로 제공해 플레이스홀더로 적용할 예정이다. 이메일 회원가입, 아이디/비밀번호 찾기는 구현하지 않음. |
| F-04 | 비회원 진입 | 앱 내 별도 진입 버튼 없음. 친구가 칭찬을 요청하며 공유한 링크를 눌러 토마토 보내기 페이지로 진입, 링크를 공유한 친구에게 도장을 보낸다. 이후 흐름은 [send-stamp.md](send-stamp.md) F-24. |

## 온보딩 슬라이드 카피

1. "친구의 멋을 발견해봐요!" / "일상 속 무심코 지나쳤던 친구의 모습에서 반짝이는 멋을 발견해보세요."
2. "토마토 도장에 마음을 담아 친구에게 전달해보세요!" / "평소 말로는 전하기 쑥스러웠던 마음을 귀여운 토마토 도장에 담아 전해보세요."
3. "받은 토마토를 차곡차곡 모아요!"(`받은 토마토` 강조색) / "친구들이 보내준 토마토 도장을 나만의 칭찬판에 기록하고 언제든 다시 확인해요."

## AC

- 온보딩 마지막 장(3번째)에서만 `멋토 시작하기`가 노출되고, 누르면 로그인 화면으로 이동한다.
- 로그인 성공 시 회원 홈([home.md](home.md))으로 이동한다.
- 칭찬 요청 공유 링크로 진입 시 토마토 보내기 페이지([send-stamp.md](send-stamp.md) F-24)로 이동하며, 링크를 공유한 친구에게 도장을 보낸다.
