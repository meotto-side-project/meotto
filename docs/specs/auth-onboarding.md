# 스플래시 · 온보딩 · 인증

IA: 멋토 → 온보딩 → 소셜 로그인 → 홈 | (공유받은 칭찬판 링크로 비회원 진입 → 비회원 홈)
Figma 섹션: 스플래시, 온보딩

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 스플래시 | 흰 배경에 Meotto 로고. 앱 진입 시 노출 후 온보딩 또는 홈으로 이동. |
| F-02 | 온보딩 | 3장 슬라이드 + 마지막 어두운 시작 화면. 하단 `다음` 버튼, 마지막 장은 `멋토 시작하기`. |
| F-03 | 소셜 로그인 | 시작 화면에서 소셜 로그인(카카오/네이버/Apple 등)으로 가입·로그인 동시 처리. 이메일 회원가입, 아이디/비밀번호 찾기는 구현하지 않음. |
| F-04 | 비회원 진입 | 앱 내 별도 진입 버튼 없음. 공유받은 칭찬판 링크를 눌러 받는 사람의 칭찬판으로 진입. 이후 흐름은 [send-stamp.md](send-stamp.md) F-24. |

## 온보딩 슬라이드 카피

1. "친구의 멋을 발견해봐요!" / "무심코 지나쳤던 친구의 모습에서 반짝이는 멋을 발견해보세요."
2. "토마토 도장에 마음을 담아 친구에게 전달해보세요!" / "말로 전하기 쑥스러웠던 마음도 토마토 도장에 담아 전해보세요."
3. "친구들이 발견한 나의 멋" / "친구들에게 받은 멋토를 모아서 나의 멋을 발견해보세요."

## AC

- 온보딩 마지막 장에서만 `멋토 시작하기`가 노출된다.
- 로그인 성공 시 회원 홈([home.md](home.md))으로 이동한다.
- 공유받은 칭찬판 링크로 진입 시 해당 친구의 칭찬판(비회원 플로우, [send-stamp.md](send-stamp.md) F-24)으로 이동한다.
