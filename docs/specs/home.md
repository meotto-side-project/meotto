# 홈 (회원 / 비회원)

IA: 홈 → 뉴 도장 / 기존 도장 → 새로 받은 도장
Figma 섹션: 회원 홈 > 메인(새로운 편지가 없을 때 / 있을 때), 내 토마토 확인 / 비회원 홈 > 메인

## 회원 홈

공통 레이아웃: 상단 "토마토 도장으로 전하는 마음" + Meotto 로고. 하단에 탭바(Home / My / Friend)와 그 오른쪽 원형 `+` 버튼(친구 선택 화면으로 이동).

홈은 받은 도장 상태에 따라 3가지 화면이 된다.

| 상태                    | 조건                          | 화면                               |
| ----------------------- | ----------------------------- | ---------------------------------- |
| 새 편지 있음 (뉴 도장)  | 확인하지 않은 도장이 있음     | F-12 봉투                          |
| 토마토 박스 (기존 도장) | 새 편지 없음 + 기존 도장 있음 | F-10 토마토 박스                   |
| 빈 상태                 | 새 편지 없음 + 기존 도장 없음 | F-11 "토마토 박스가 텅 비어있어요" |

새 편지를 확인(F-13)하고 나면 토마토 박스(F-10)가 보인다.

| ID   | 기능           | 설명                                                                                                                                                                                            |
| ---- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-10 | 토마토 박스    | 선반 3단 위에 받은 토마토가 놓이고, 선반 이름표에 보낸 친구 이름이 붙는다. 한 줄에 최대 3개.                                                                                                    |
| F-11 | 빈 상태        | "토마토 박스가 텅 비어있어요" 문구만 노출. 회원 빈 상태에는 별도 CTA가 없고 `+` 버튼으로 보낸다.                                                                                                |
| F-12 | 새 편지 있음   | 봉투 일러스트와 `New N` 뱃지(N = 새로 받은 도장 수). 봉투를 탭하면 F-13으로 이동.                                                                                                               |
| F-13 | 내 토마토 확인 | 편지지 형태 화면: From(보낸 친구), 날짜, 칭찬 키워드 칩, 메시지. 새 편지가 2개 이상이면 하단 `다음` 버튼으로 다음 편지를 보고, 마지막 편지까지 보면 홈으로 이동한다. 헤더에 뒤로가기 버튼 있음. |
| F-14 | `+` 버튼       | 탭바 옆 `+` 버튼 → 친구 선택 화면([send-stamp.md](send-stamp.md) F-20). 받는 친구는 그곳에서 고른다.                                                                                            |

## 비회원 홈

비회원 홈은 친구의 토마토 박스 화면이다(받은 도장이 선반 + 이름표로 보이고, 도장이 없으면 빈 상태). 탭바는 없고 하단에 두 가지 액션만 있다. 비회원이 이 화면에 들어오는 경로는 미확정이다(공유 링크 접속 / IA의 `비회원 로그인` — Open Questions 참고).

| ID   | 기능             | 설명                                                                                                                                    |
| ---- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| F-15 | 토마토 보내기    | 지금 보고 있는 그 친구에게 보내는 흐름. 받는 사람이 이미 정해져 있어 친구 선택 단계가 없다. [send-stamp.md](send-stamp.md) F-24로 이동. |
| F-16 | 내 칭찬판 만들기 | 회원가입으로 이동 ([auth-onboarding.md](auth-onboarding.md) F-03).                                                                      |

## 연결

- 회원 `+` 버튼 → 친구 선택 ([send-stamp.md](send-stamp.md) F-20)
- 비회원 `토마토 보내기` → 친구 선택 없이 메시지 작성 ([send-stamp.md](send-stamp.md) F-24)
- My 탭 → [my-board.md](my-board.md), Friend 탭 → [friends.md](friends.md)

## AC

- 새 편지가 있으면 F-12, 없고 기존 도장이 있으면 F-10, 둘 다 없으면 F-11을 보여준다.
- 새 편지가 2개 이상이면 F-13에 `다음` 버튼이 있고, 누를 때마다 다음 편지를 보여준다. 마지막 편지까지 확인하면 홈으로 이동하고 F-10이 보인다.
- 회원 홈에는 탭바와 `+` 버튼이 항상 보인다. 비회원 홈에는 보이지 않는다.

## Open Questions

- 새 편지가 1개일 때 F-13 하단 버튼이 무엇인지. Figma의 `다음` 화면은 2개 이상일 때의 모습.
- 토마토 박스에서 도장 개수가 많아질 때 스크롤/페이지 방식.
- 공유 링크가 가리키는 친구가 비공개/이름만 설정([mypage-settings.md](mypage-settings.md) F-43)일 때 비회원 홈에 무엇이 보이는지.
- 비회원 홈 진입 경로: 친구가 보낸 공유 링크로만 들어오는지, IA의 `비회원 로그인`(온보딩에서 분기)도 있는지. 후자라면 누구의 토마토 박스가 보이는지.
- 회원이 공유 링크로 접속하면 비회원 홈과 같은 화면인지, 회원 흐름으로 바뀌는지.
