# 홈 (회원 / 비회원)

IA: 홈 → 뉴 도장 / 기존 도장 → 새로 받은 도장
Figma 섹션: 회원 홈 > 메인(새로운 편지가 없을 때 / 있을 때), 내 토마토 확인 / 비회원 홈 > 메인

## 회원 홈

공통 레이아웃: 상단 "토마토 도장으로 전하는 마음" + Meotto 로고. 하단에 탭바(Home / My / Friend)와 그 오른쪽 원형 `+` 버튼(친구 선택 화면으로 이동).

홈은 받은 도장 상태에 따라 3가지 화면이 된다.

| 상태                    | 조건                                      | 화면                                         |
| ----------------------- | ----------------------------------------- | -------------------------------------------- |
| 새 편지 있음 (뉴 도장)  | 확인하지 않은 도장이 있음(받은 달과 무관) | F-12 봉투                                    |
| 토마토 박스 (기존 도장) | 새 편지 없음 + 이번 달 받은 도장 있음     | F-10 토마토 박스                             |
| 빈 상태                 | 새 편지 없음 + 이번 달 받은 도장 없음     | F-11 "토마토 박스가 텅 비어있어요" + 빈 선반 |

새 편지를 확인(F-13)하고 나면 위 표를 다시 적용한다. 이번 달 받은 도장이 있으면 토마토 박스(F-10), 없으면(지난달 편지만 있었던 경우) 빈 상태(F-11)가 보인다.

| ID   | 기능           | 설명                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-10 | 토마토 박스    | 로고 아래 `나의 ○월 토마토 N` 배지(클립 장식, ○는 현재 월이라 달마다 바뀐다. N은 이번 달에 받은 토마토 수이며 월이 바뀌면 0으로 초기화되고, 박스에 놓인 토마토 수와 항상 같다). 선반 위에 받은 토마토가 놓이고, 선반 이름표에 보낸 친구 이름이 붙는다(표시 규칙은 아래 "이름표 표시 규칙"). 한 줄에 최대 3개. 선반이 3단 이상으로 늘어나면 화면이 세로 스크롤되며, 하단 탭바가 내용 위에 겹쳐 보인다. |
| F-11 | 빈 상태        | `나의 ○월 토마토 0` 배지, "토마토 박스가 텅 비어있어요" 문구, 빈 선반 1개. 회원 빈 상태에는 별도 CTA가 없고 `+` 버튼으로 보낸다.                                                                                                                                                                                                                                                                      |
| F-12 | 새 편지 있음   | 봉투 일러스트와 `New N` 뱃지(N = 새로 받은 도장 수, 클립 장식). 봉투 아래 안내 문구 "편지를 클릭해서 받은 토마토를 확인해보세요!". 봉투를 탭하면 F-13으로 이동.                                                                                                                                                                                                                                       |
| F-13 | 내 토마토 확인 | 편지지 카드 화면: 날짜, From(보낸 친구, 토마토 아이콘), 칭찬 키워드 칩(여러 개 가능), 메시지. 상단에 페이지 도트, 양옆에 이웃 편지 카드가 일부 보이는 캐러셀이며 좌우 스와이프로 편지를 넘긴다. 헤더에 뒤로가기 버튼, 하단 `확인` 버튼은 모든 편지에서 보인다.                                                                                                                                        |
| F-14 | `+` 버튼       | 탭바 옆 `+` 버튼 → 친구 선택 화면([send-stamp.md](send-stamp.md) F-20). 받는 친구는 그곳에서 고른다.                                                                                                                                                                                                                                                                                                  |

### 이름표 표시 규칙

선반 이름표(F-10)는 회원 홈과 비회원 홈에 똑같이 적용된다. 설정은 [mypage-settings.md](mypage-settings.md) F-42, F-43.

| 상황                                                  | 이름표                                                     |
| ----------------------------------------------------- | ---------------------------------------------------------- |
| 기본                                                  | 보낸 친구 이름                                             |
| 칭찬판 주인이 `내 칭찬판 공개` Off (F-42)             | 이름표가 아예 없음(받은 칭찬의 보낸 사람 이름을 모두 숨김). 아래 F-43 설정보다 우선 |
| 보낸 사람이 `보낸 칭찬 공개`를 `비공개`로 설정 (F-43) | 상대의 친구들에게 그 도장의 이름표가 `------`로 가려짐     |
| 보낸 사람이 `보낸 칭찬 공개`를 `이름만`으로 설정 (F-43) | 이름은 보이고 내용(메시지)만 숨김                          |

## 비회원 홈

비회원 홈은 친구의 토마토 박스 화면이다. 로고 아래 배지가 `○○의 ○월 토마토 N`(친구 이름, 현재 월)으로 표시되고, 받은 도장이 선반 + 이름표로 보이며, 도장이 없으면 빈 상태다. 탭바와 `+` 버튼은 없다. 비회원 홈은 **토마토 보내기([send-stamp.md](send-stamp.md) F-24)를 완료한 후 나타나는 화면**이다. 친구가 보낸 공유 링크로 접속하면 매번 토마토 보내기가 먼저 열린다(앱 진입이나 온보딩에서 따로 들어가는 경로는 없다).

| ID   | 기능             | 설명                                                                                                                                                                                                                                                                                                    |
| ---- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-16 | 내 칭찬판 만들기 | 전송 완료 후 보이는 비회원 홈 하단의 단일 검정 버튼. 접속한 사람이 비회원이면 회원가입/로그인 시작 화면(빨간 `회원가입`, 검정 `로그인`)으로 이동([auth-onboarding.md](auth-onboarding.md) F-03), 이미 회원이면 내 칭찬판([my-board.md](my-board.md))으로 바로 이동. 회원도 공유 링크로 접속해 토마토 보내기를 완료하면 이 화면이 그대로 보인다. |

## 연결

- 회원 `+` 버튼 → 친구 선택 ([send-stamp.md](send-stamp.md) F-20)
- 공유 링크 접속 → 토마토 보내기 ([send-stamp.md](send-stamp.md) F-24) → 전송 완료 → 비회원 홈
- My 탭 → [my-board.md](my-board.md), Friend 탭 → [friends.md](friends.md)

## AC

- 새 편지는 받은 달과 상관없이, 지난달에 받고 아직 확인하지 않은 편지도 새 편지로 보여준다.
- 새 편지가 있으면 F-12, 없고 이번 달에 받은 도장이 있으면 F-10, 없으면 F-11을 보여준다. 토마토 박스와 빈 상태는 이번 달 기준이라 월이 바뀌면 박스가 초기화되어 빈 상태가 된다.
- F-13에서 좌우 스와이프로 편지를 넘기고, `확인` 버튼은 모든 편지에서 보인다. `확인`을 누르면 홈으로 이동하고, 이번 달 받은 도장이 있으면 F-10, 없으면 F-11이 보인다.
- 토마토 박스는 선반 한 줄에 최대 3개를 놓고, 줄이 늘어나면 세로로 스크롤된다.
- `나의 ○월 토마토 N` 배지의 월은 현재 월이다. N은 이번 달에 받은 토마토 수이며 월이 바뀌면 초기화되고, 박스에 놓인 토마토 수와 같다.
- 이름표는 이름표 표시 규칙에 따라 회원 홈과 비회원 홈에 똑같이 표시된다.
- 회원 홈에는 탭바와 `+` 버튼이 항상 보인다. 비회원 홈에는 보이지 않는다.
- 비회원 홈은 토마토 보내기(F-24)를 완료한 후 나타나며, 링크가 가리키는 친구의 토마토 박스를 보여준다. 회원이 접속해도 똑같다.
- 공유 링크는 열 때마다 토마토 보내기(F-24)부터 시작한다. 전송을 마친 뒤 같은 링크를 다시 열어도 마찬가지이며, 건너뛰거나 재전송을 막지 않는다. 비회원 홈 화면 안에는 다시 보내는 경로가 없다.
- 비회원 홈의 `내 칭찬판 만들기`는 비회원이면 회원가입/로그인 화면으로, 회원이면 내 칭찬판으로 이동한다.
