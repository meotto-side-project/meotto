# 회원 홈

IA: 홈 → 뉴 도장 / 기존 도장 → 새로 받은 도장
Figma 섹션: 회원 홈 > 메인(새로운 편지가 없을 때 / 있을 때), 내 토마토 확인
하단 탭: Home 선택 상태.

| ID | 기능 | 설명 |
|---|---|---|
| F-10 | 홈 메인 | 헤더 "오늘도 멋토를 보내볼까요?", 토마토 박스(도장 격자). 새 편지 유무에 따라 2가지 상태. |
| F-11 | 새 편지 없음 | "토마토 박스가 텅 비어있어요" 빈 상태. `토마토 보내기` 유도. |
| F-12 | 새 편지 있음 | 봉투 형태로 노출, 탭하면 내 토마토 확인(F-13)으로 이동. |
| F-13 | 내 토마토 확인 | 받은 도장 상세: From, 날짜, 칭찬 키워드(예: 재미있어요), 메시지. `다음`으로 닫기/다음 편지. `New` 표시와 개수(예: 3), `내 도장 전체보기` 진입. |
| F-14 | 뉴 도장 / 기존 도장 | 홈의 두 갈래. 뉴 도장은 새로 받은 도장 확인 흐름, 기존 도장은 보관 도장 보기. |

## 연결

- `토마토 보내기` → [send-stamp.md](send-stamp.md) F-20
- `내 도장 전체보기` → [my-board.md](my-board.md) F-30

## AC

- 새 편지가 없으면 F-11, 있으면 F-12 상태를 보여준다.
- 새 편지를 확인(F-13)하면 `New` 표시가 사라진다 (확인 필요).
