# 마이페이지 · 서비스 설정

IA: 칭찬도장 → 마이페이지 → 내 프로필 / 칭찬판 공유하기 / 서비스 설정(알림, 칭찬판 공개 여부) / 로그아웃 / 회원탈퇴
Figma 섹션: 내 칭찬판 > 내 계정관리
진입: 내 칭찬판(My) 메인 우측 상단 `⋯`(점 3개) 버튼 → 계정관리.

| ID | 기능 | 설명 |
|---|---|---|
| F-40 | 내 프로필 | 프로필 사진, 이름(표시명), 아이디(예: Jiun_kim), `프로필 변경` 후 `저장`. |
| F-41 | 서비스 설정 | `칭찬 알림` On/Off 토글, `내 칭찬판 공개` On/Off 토글. |
| F-42 | 공개 범위 | 공개 시 `전체 / 이름만 / 비공개` 선택. |
| F-43 | 로그아웃 | 로그아웃 후 로그인 화면. |
| F-44 | 회원탈퇴 | 탈퇴 진행. 확인 단계 필요. |
| F-45 | 칭찬판 공유하기 | 계정관리의 `칭찬판 공유` 영역. QR코드, 링크 주소 복사(예: `www.jiunchingchan.com`), SNS 공유. (IA상 위치는 내 프로필 다음, ID는 추가 순) |

## AC

- 알림 토글은 [notifications.md](notifications.md) F-60 발송 여부를 제어한다.
- 공개 범위 `전체 / 이름만 / 비공개`는 친구 칭찬판 노출([friends.md](friends.md) F-53)에 반영된다.
- 로그아웃 후 보호된 화면에 접근할 수 없다.
- 칭찬판 공개 범위 설정(F-42)은 F-45 공유 링크로 보는 사람에게 적용된다 (확인 필요).
