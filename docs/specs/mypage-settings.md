# 마이페이지 · 서비스 설정

IA: 칭찬도장 → 마이페이지 → 내 프로필 / 칭찬판 공유하기 / 서비스 설정(알림, 칭찬판 공개 여부, 보낸 칭찬 공개) / 로그아웃 / 회원탈퇴
Figma 섹션: 내 칭찬판 > 내 계정관리
진입: 내 칭찬판(My) 메인 우측 상단 `⋯`(점 3개) 버튼 → 계정관리. 계정관리는 칭찬판 위에 올라오는 바텀시트이며 우측 상단 X로 닫는다.

| ID   | 기능            | 설명                                                                                                                                                                  |
| ---- | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-40 | 내 프로필       | 프로필 사진(원형), 닉네임(이름), `@아이디`, `프로필 변경` 버튼. 사용자 구분은 아이디로 하며 아이디는 다른 사용자와 중복될 수 없다. 닉네임은 표시용 이름이다. 가입 시 닉네임(이름), 프로필 사진(선택), 아이디를 입력하는데, 아이디는 서버가 자동으로 정한 값이 입력창 placeholder에 채워져 있고 사용자는 그대로 쓰거나 고칠 수 있다. 버튼을 누르면 프로필 변경 시트: 뒤로가기, `닉네임` 입력, `프로필 사진` 업로드 영역, `저장` 버튼. |
| F-41 | 칭찬판 공유하기 | 계정관리의 `칭찬판 공유` 영역. QR코드, 링크 주소 복사(예: `www.jiunchingchan.com`), SNS 공유(카카오톡, 네이버, 구글 아이콘).                                          |
| F-42 | 서비스 설정     | `칭찬 알림` On/Off 토글, `내 칭찬판 공개` On/Off 토글. `내 칭찬판 공개`를 Off하면 다른 사람이 내 칭찬판을 열어도 제한된 화면만 보이고([friends.md](friends.md) F-53), 공유 링크로 보는 홈 토마토 박스에서는 받은 칭찬의 보낸 사람 이름표가 모두 사라진다. |
| F-43 | 보낸 칭찬 공개  | 서비스 설정 안의 `보낸 칭찬 공개` 항목. `전체 / 이름만 / 비공개` 중 하나를 고르는 세그먼트(기본 `전체`). 내가 보낸 칭찬을 상대 이외의 사람(상대의 친구들)에게 어디까지 보여줄지 정한다: `전체` = 내용까지 모두 볼 수 있음, `이름만` = 보낸 사람 이름만 보이고 내용(메시지)은 숨김, `비공개` = 이름과 내용 모두 비공개(이름표는 `------`로 표시). |
| F-44 | 로그아웃        | 로그아웃 후 로그인 화면.                                                                                                                                              |

## AC

- 알림 토글은 [notifications.md](notifications.md) F-60 발송 여부를 제어한다.
- `내 칭찬판 공개`(F-42)는 친구 탭에서 친구를 눌러 내 칭찬판을 볼 때([friends.md](friends.md) F-53)와 공유 링크(F-41)로 열리는 홈 토마토 박스([home.md](home.md))에 적용된다. Off이면 다른 사람에게는 제한된 칭찬판(프로필, 나와 주고 받은 토마토 수, `토마토 보내기`, 상자 속 전체 토마토 수와 도장 격자, 많이 받은 칭찬)만 보이고 칭찬판 상세 카드 등 나머지는 볼 수 없으며, 공유 링크로 보는 홈 토마토 박스에서는 이름표가 아예 없다. 공유 링크는 칭찬판이 아니라 토마토 보내기와 토마토 박스로 연결된다.
- `보낸 칭찬 공개`(F-43)는 `전체 / 이름만 / 비공개` 중 하나만 선택된다. `전체`는 상대의 친구들도 내 칭찬의 내용을 볼 수 있고, `이름만`은 상대의 친구들에게 이름만 보이고 내용은 숨기며, `비공개`는 상대의 친구들에게 이름과 내용을 모두 숨긴다(이름표 `------`).
- 두 설정의 결과(이름표 없음 / `------`)는 회원과 비회원 구분 없이 홈 토마토 박스([home.md](home.md) 이름표 표시 규칙)에 똑같이 적용된다.
- F-42와 F-43이 함께 걸린 도장은 F-42가 우선한다. 칭찬판 주인이 `내 칭찬판 공개`를 Off하면 보낸 사람의 `보낸 칭찬 공개` 설정과 상관없이 이름표가 아예 없다.
- 프로필 변경 시트에서 `저장`을 누르면 닉네임과 프로필 사진이 반영된다.
- 아이디는 다른 사용자와 중복될 수 없다. 중복된 아이디로는 가입할 수 없다.
- 가입 시 아이디 입력창에는 서버가 자동으로 정한 아이디가 placeholder로 들어 있고, 사용자는 그대로 두거나 고칠 수 있다. 프로필 사진은 선택이다.
- 닉네임은 저장한 뒤에도 다시 바꿀 수 있다. 닉네임을 바꾸면 친구 목록 등 기존 관계는 그대로 유지되고, 화면에는 바뀐 닉네임으로 표시된다.
- 회원탈퇴는 확인 팝업에서 `탈퇴하기`를 눌러야 진행되고, `취소`를 누르면 팝업만 닫힌다. 완료 팝업의 `확인`을 누르면 로그인 화면으로 이동한다.
- 로그아웃 후 보호된 화면에 접근할 수 없다.

## Open Questions

- 회원탈퇴 시 내가 보낸/받은 도장 데이터를 어떻게 처리하는지(삭제, 익명화 등).
- 가입 이후 아이디를 변경할 수 있는지(프로필 변경 시트에 아이디 항목이 필요한지). 아직 정해지지 않음.
- 닉네임과 아이디의 길이·허용 문자 제한.
- 프로필 사진 업로드 방식(앨범 선택, 카메라)과 제한(용량, 비율). 아직 정해지지 않음.
- `보낸 칭찬 공개`(F-43)를 보는 사람별로 어떻게 적용할지. 노출 대상이 `상대의 친구들`로 정해져 있어서, 받는 사람 본인, 받는 사람과 친구가 아닌 회원, 비회원(공유 링크)에게 적용할 정책이 따로 필요하다. 정책이 정해지기 전까지 홈 토마토 박스의 이름표 규칙([home.md](home.md))은 회원·비회원 구분 없이 같다.
