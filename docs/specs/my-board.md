# 내 칭찬판 (My)

IA: 칭찬도장 → 받은 도장 / 뱃지 컬렉션 / 많이 받은 칭찬 / 주고 받은 토마토
Figma 섹션: 내 칭찬판 > 메인 / 칭찬판 클릭 플로우 / 내 뱃지 → 공유
하단 탭: My 선택 상태.

| ID   | 기능                           | 설명                                                                                                                                                                                                    |
| ---- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-30 | 칭찬판 메인                    | "총 N개의 토마토 도장을 받았어요!", 도장 격자(5×3). 새로 받은 토마토(아직 읽지 않은 것)는 파란 도장, 기존 도장은 빨간 도장, 남은 칸은 빈 도장. 가로 스와이프로 판 전환. 상단 알림 배너(F-61) 닫기 가능. |
| F-31 | 뱃지 컬렉션                    | 케찹, 토마토주스, 파스타, 피자, 카프레제, 마녀스프 등 6개 격자 + `전체보기`. 탭 시 뱃지 상세(획득 사유 문구 "…해서 받은 케찹 뱃지") + `내 뱃지 공유하기`.                                               |
| F-32 | 많이 받은 칭찬                 | 받은 키워드 칩 상위 N개.                                                                                                                                                                                |
| F-33 | 주고 받은 토마토               | 친구별 주고받은 개수 리스트("김지운 · 16개")                                                                                                                                                            |
| F-34 | 도장 상세 (칭찬판 클릭 플로우) | 칭찬판의 도장 탭 → 날짜·보낸 친구·키워드·메시지 상세.                                                                                                                                                   |
| F-35 | 뱃지 공유                      | 뱃지 이미지 + 공유 시트: 카카오톡, 네이버, 저장하기, 더보기.                                                                                                                                            |

메인 우측 상단 `⋯`(점 3개) 버튼은 계정관리로 이동한다. `칭찬판 공유하기`(QR코드, 링크, SNS)를 포함한 계정관리는 [mypage-settings.md](mypage-settings.md) F-40~F-45 참고.

## AC

- 총 도장 수는 받은 도장 전체 개수와 일치한다(파란 도장 + 빨간 도장).
- 읽지 않은 도장은 파란색, 읽은 도장은 빨간색으로 표시한다.

## Open Questions

- 뱃지 **획득 조건**: 칭찬 키워드와 매핑되는가, 개수 기준인가. 수치는 범위 밖.
- 도장 격자 판이 넘어갈 때의 규칙.
- 파란 도장이 빨간 도장으로 바뀌는 시점이 홈에서 새 편지를 확인할 때도 포함인지.
- 알림 배너(F-61)는 알림 용도라 본체 탭 동작 없이 X(닫기)만 동작하는 것이 맞는지.
