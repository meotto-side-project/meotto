# 내 칭찬판 (My)

IA: 칭찬도장 → 받은 도장 / 뱃지 컬렉션 / 많이 받은 칭찬 / 주고 받은 토마토
Figma 섹션: 내 칭찬판 > 메인 / 칭찬판 클릭 플로우 / 내 뱃지 → 공유
하단 탭: My 선택 상태.

| ID | 기능 | 설명 |
|---|---|---|
| F-30 | 칭찬판 메인 | "총 N개의 토마토 도장을 받았어요!", 도장 격자(5×3, 일부는 파란 도장/빈 도장), 가로 스와이프로 판 전환. 상단 알림 배너(F-61) 닫기 가능. |
| F-31 | 뱃지 컬렉션 | 케찹, 토마토주스, 파스타, 피자, 카프레제, 마녀스프 등 6개 격자 + `전체보기`. 탭 시 뱃지 상세(획득 사유 문구 "…해서 받은 케찹 뱃지") + `내 뱃지 공유하기`. |
| F-32 | 많이 받은 칭찬 | 받은 키워드 칩 상위 N개. |
| F-33 | 주고 받은 토마토 | 친구별 주고받은 개수 리스트("김지운 · 16개") + `전체보기`. |
| F-34 | 도장 상세 (칭찬판 클릭 플로우) | 칭찬판의 도장 탭 → 날짜·보낸 친구·키워드·메시지 상세. |
| F-35 | 뱃지 공유 | 뱃지 이미지 + 공유 시트: 카카오톡, 네이버, 저장하기, 더보기. |
| F-36 | 칭찬판 공유 | QR코드, 링크 주소 복사(예: `www.jiunchingchan.com`), SNS 공유. 진입은 [mypage-settings.md](mypage-settings.md)의 `칭찬판 공유하기`. |

## AC

- 총 도장 수는 받은 도장 전체 개수와 일치한다.
- 칭찬판 공개 범위 설정([mypage-settings.md](mypage-settings.md) F-42)은 F-36 공유 링크로 보는 사람에게 적용된다 (확인 필요).
