# 내 칭찬판 (My)

IA: 칭찬도장 → 받은 도장 / 배지 컬렉션 / 많이 받은 칭찬 / 주고 받은 토마토
Figma 섹션: 내 칭찬판 > 메인 / 칭찬판 클릭 플로우 / 내 배지 → 공유
하단 탭: My 선택 상태.

| ID   | 기능                           | 설명                                                                                                                                                                                                                                                                                                       |
| ---- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-30 | 칭찬판 메인                    | "내 상자 속 전체 토마토 N개"(N은 강조색 배지), 상자 이미지 안의 도장 격자(5×3). 새로 받은 토마토(아직 읽지 않은 것)는 파란 도장, 기존 도장은 빨간 도장, 남은 칸은 빈 도장. 15칸이 다 차면 다음 격자판으로 넘어가며, 가로 스와이프로 판 전환. 상단 알림 배너(F-64, 검정 바 + 🔔 문구 + X)는 알림 용도라 X(닫기)만 동작하고 본체 탭 동작은 없다. |
| F-31 | 배지 컬렉션                    | 메인에는 배지 6개 격자(시안 예시: 케찹, 파스타, 샐러드, 피자, 햄버거, 주스. 배지 종류와 이름은 확정 아님) + `전체보기`. `전체보기`는 "배지 컬렉션" 전체 화면(뒤로가기, 3열 격자, 세로 스크롤)으로 이동하며, 아직 획득하지 못한 배지는 자물쇠 아이콘의 잠금 타일로 보인다. 배지를 탭하면 배지 상세 모달: 제목 "{배지 이름} 배지"(예: 햄버거 배지), 페이지 도트(좌우로 다른 배지), 배지 이미지, 획득 사유 문구("…해서 받은 케찹 배지"), `내 배지 공유하기` 버튼, 하단 X(닫기). |
| F-32 | 많이 받은 칭찬                 | 받은 키워드 칩 상위 N개.                                                                                                                                                                                                                                                                                   |
| F-33 | 주고 받은 토마토               | 친구별 주고받은 개수 리스트("김지운 · 16개")                                                                                                                                                                                                                                                               |
| F-34 | 도장 상세 (칭찬판 클릭 플로우) | 칭찬판의 도장을 탭하면 격자 아래에 상세 카드가 펼쳐진다. 선택한 도장은 강조(흰 테두리)되고 나머지 도장은 흐려진다. 카드 내용: 날짜, To/From 친구 이름(토마토 아이콘), 칭찬 키워드 칩(여러 개 가능), 메시지.                                                                                                |
| F-35 | 배지 공유                      | `내 배지 공유하기`를 누르면 바텀시트 "내 배지 공유하기": 배지 이미지와 이름, 공유 대상(카카오톡, 네이버, 저장하기, 더보기), `공유하기` 버튼, X(닫기).                                                                                                                                                     |

메인 우측 상단 `⋯`(점 3개) 버튼은 계정관리로 이동한다. `칭찬판 공유하기`(QR코드, 링크, SNS)를 포함한 계정관리는 [mypage-settings.md](mypage-settings.md) F-40~F-45 참고.

## AC

- "내 상자 속 전체 토마토" 수는 받은 도장 전체 개수와 일치한다(파란 도장 + 빨간 도장).
- 읽지 않은 도장은 파란색, 읽은 도장은 빨간색으로 표시한다.
- 홈 새 편지 확인(F-13)에서 `확인`을 누르면 새 편지가 전부 읽음 처리되어 파란 도장이 빨간 도장으로 바뀐다([home.md](home.md)). `확인` 없이 뒤로가기로 나가면 바뀌지 않는다.
- 격자판은 상자 이미지 안에 15칸(5×3)으로 보이며, 도장이 다 차면 다음 격자판으로 넘어간다.
- 도장을 탭하면 해당 도장만 강조되고 상세 카드가 격자 아래에 열린다.
