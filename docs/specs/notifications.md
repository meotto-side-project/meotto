# 알림

Figma 섹션: "11/02" > 알림창 (잠금화면 알림, 내 칭찬판 상단 배너)
설정: 계정관리 > 서비스 설정 > `칭찬 알림` 토글 ([mypage-settings.md](mypage-settings.md) 서비스 설정)

푸시 알림(F-60~F-63)은 앱 아이콘(토마토) + 제목 + 본문 + 수신 시각으로 구성된다. 인앱 배너는 F-64.

| ID   | 기능            | 발송 조건                                   | 제목                      | 본문                                                  |
| ---- | --------------- | ------------------------------------------- | ------------------------- | ----------------------------------------------------- |
| F-60 | 새 토마토 도착  | 친구가 토마토 편지를 보냈을 때              | `{보낸 사람}`             | 띵동! `{보낸 사람}`님이 보낸 새 토마토가 도착했어요. |
| F-61 | 찌르기          | 친구가 내 토마토에 반응을 남겼을 때 (Figma 11/02에는 없음) | `{찌른 사람}`             | `{찌른 사람}`님이 당신의 토마토를 찌르고 갔어요.     |
| F-62 | 토마토 썩음     | 사용자가 앱에 7일 동안 접속하지 않았을 때   | Meotto                    | `{사용자 본인}`님의 토마토가 썩고 있어요!             |
| F-63 | 보내기 리마인드 | 매일                                        | 오늘도 멋토를 보내볼까요? | 친구에게 오늘의 토마토를 전달해보세요.                |

| ID   | 기능      | 설명                                                                                   |
| ---- | --------- | -------------------------------------------------------------------------------------- |
| F-64 | 인앱 배너 | 내 칭찬판 상단 배너. 🔔 "띵동! `{사용자 본인}`님에게 새 토마토가 도착했어요" + `X` 닫기. |

## AC

- 도장 수신 시 받는 사람에게 F-60이 발송된다 ([send-stamp.md](send-stamp.md) F-22 `편지 보내기` 시점).
- F-60, F-61의 제목과 본문에는 상대방 표시명이 들어간다.
- F-61은 반응 관련 인터랙션이 추가되는 경우에만 사용한다.
- F-62는 마지막 앱 접속 후 7일이 지나면 발송된다.
- F-63은 매일 발송된다.
- 수신자의 `칭찬 알림`이 Off면 F-60을 발송하지 않는다.
- F-64는 `X`를 누르면 닫힌다.

## 범위 밖

- 알림 발송 인프라.

## Open Questions

- **[논의 필요]** `칭찬 알림` 토글 하나가 F-60~F-64 전체를 제어하는지, 유형별 설정이 필요한지.
- **[논의 필요]** F-61 찌르기: '반응' 인터랙션 자체가 아직 정의되지 않음. 어디서 어떤 반응을 남기는지 정해지면 활성화.
- **[논의 필요]** F-62 토마토 썩음: 7일 후 한 번만 보내는지 반복 발송하는지, 썩은 토마토의 화면 표현. Figma 메모: 파란 토마토 = 안 읽은 토마토, 초록+빨강 = 안 익은/썩은 토마토(검토 중).
- **[논의 필요]** F-63 리마인드: 발송 시각, 오늘 이미 보낸 사용자 제외 여부.
- **[논의 필요]** 알림 탭 시 이동 화면. Figma 코멘트 제안: F-62·F-63 → 홈, F-60 → 받은 편지([home.md](home.md) F-13), F-61 → 친구 프로필.
- **[논의 필요]** F-64 배너 노출 시점과 기간(새 토마토가 있을 때마다? 닫으면 다시 안 보임?).
- **[논의 필요]** 비회원에게 발송되는 알림이 있는지(비회원은 앱 미설치 가능).
- **[논의 필요]** 문구 수정 및 추가로 필요한 알림 종류.
