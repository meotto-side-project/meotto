# 알림

Figma 섹션: 알림창 (잠금화면 알림), 내 칭찬판 상단 배너

| ID | 기능 | 설명 |
|---|---|---|
| F-60 | 푸시 알림 | 잠금화면 알림: "띵동! ○○님이 보낸 새 토마토가 도착했어요." 설정에서 On/Off. |
| F-61 | 인앱 배너 | 칭찬판 상단 배너("띵동! ○○님에게 새 토마토가 도착했어요"), 닫기(X) 가능. |

## AC

- 도장 수신 시 F-60이 발송된다. 수신자의 `칭찬 알림`이 Off면 발송하지 않는다 ([mypage-settings.md](mypage-settings.md) F-42).
- F-61은 X를 누르면 닫힌다.

## 범위 밖

- 알림 발송 인프라.

## Open Questions

- 칭찬 알림 Off 시에도 인앱 배너는 노출되는가.
- 배너 문구가 두 가지("지운님에게…", "예은님에게…")로 보임. 수신자/발신자 중 누구 이름인지 확정 필요.
