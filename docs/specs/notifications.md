# 알림

Figma 섹션: "10/26" > 알림창 (잠금화면 알림)
설정: 계정관리 > 서비스 설정 > `칭찬 알림` 토글 ([mypage-settings.md](mypage-settings.md) 서비스 설정)

모든 알림은 푸시 알림이며 앱 아이콘(토마토) + 제목 + 본문 + 수신 시각으로 구성된다.

| ID   | 기능           | 제목           | 본문                                                  |
| ---- | -------------- | -------------- | ----------------------------------------------------- |
| F-60 | 새 토마토 도착 | `{보낸 사람}`  | 띵동! `{보낸 사람}`님이 보낸 새 토마토가 도착했어요. |
| F-61 | 찌르기         | `{찌른 사람}`  | `{찌른 사람}`님이 당신의 토마토를 찌르고 갔어요.     |
| F-62 | 토마토 썩음    | Meotto         | `{이름}`님의 토마토가 썩고 있어요!                    |
| F-63 | 보내기 리마인드 | 오늘도 멋토를 보내볼까요? | 친구에게 오늘의 토마토를 전달해보세요.     |

## AC

- 도장 수신 시 받는 사람에게 F-60이 발송된다 ([send-stamp.md](send-stamp.md) F-22 `다음` 시점).
- F-60, F-61의 제목과 본문에는 상대방 표시명이 들어간다.
- 수신자의 `칭찬 알림`이 Off면 F-60을 발송하지 않는다.

## 범위 밖

- 알림 발송 인프라.
- 인앱 배너. Figma 10/26 기준 알림은 푸시만 있음.
