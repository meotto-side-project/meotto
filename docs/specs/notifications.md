# 알림

Figma 섹션: "11/02" > 알림창 (잠금화면 알림, 내 칭찬판 상단 배너)
설정: 계정관리 > 서비스 설정 > `칭찬 알림` 토글 ([mypage-settings.md](mypage-settings.md) 서비스 설정)

푸시 알림(F-60~F-63)은 앱 아이콘(토마토) + 제목 + 본문 + 수신 시각으로 구성된다. 인앱 배너는 F-64.
`탭 시 이동`의 F-10, F-13은 [home.md](home.md), F-53은 [friends.md](friends.md) 참고.

## AC

- 도장 수신 시 받는 사람에게 F-60이 발송된다 ([send-stamp.md](send-stamp.md) F-22 `편지 보내기` 시점).
- F-60, F-61의 제목과 본문에는 상대방 표시명이 들어간다.
- F-62는 마지막 앱 접속 후 7일이 지나면 발송되고, 미접속이 이어지면 7일마다 1회 다시 발송된다.
- F-63은 매일 저녁 8시에 발송된다. 그날 이미 토마토를 보낸 사용자에게는 발송하지 않는다.
- 수신자의 `칭찬 알림`이 Off면 푸시 알림(F-60~F-63)을 발송하지 않는다. 인앱 배너(F-64)는 토글과 무관하다.
- 푸시 알림을 탭하면 위 표의 `탭 시 이동` 화면으로 이동한다. F-60은 해당 메시지를 바로 연다.
- 비회원에게는 푸시 알림(F-60~F-63)을 발송하지 않는다.
- F-64는 안 읽은 토마토가 있을 때 노출되고, 안 읽은 토마토를 모두 읽으면 자동으로 사라진다.
- F-64는 `X`를 누르면 닫히고, 다음 새 토마토가 도착하기 전까지 다시 노출되지 않는다.

## 범위 밖

- 알림 발송 인프라.
- F-61 찌르기: 이번 MVP에 포함하지 않고 다음 MVP에서 반응 인터랙션과 함께 구현한다.
