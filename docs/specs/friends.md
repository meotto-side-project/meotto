# 친구

IA: 친구 → 검색 → 친구 추가 → 친구 목록 → 친구 칭찬판 → 친구 도장찍기
Figma 섹션: 친구
하단 탭: Friend 선택 상태.

| ID | 기능 | 설명 |
|---|---|---|
| F-50 | 친구 검색 | `친구 이름 검색` 입력. |
| F-51 | 친구 추가 | `+ 친구 추가하기`. |
| F-52 | 친구 목록 | 친구별 "나와 주고 받은 토마토 N개" + `토마토 보내기` 바로가기. 스크롤로 전체 목록 노출(별도 `전체보기` 버튼 없음). |
| F-53 | 친구 칭찬판 | 친구 프로필, 총 토마토 N개, 도장 격자, 많이 받은 칭찬, 토마토 기록(보낸/받은, 일시), 뱃지 컬렉션. 친구의 공개 범위 설정에 따라 노출 제한. |
| F-54 | 친구 도장찍기 | 친구 칭찬판에서 곧바로 도장 보내기. [send-stamp.md](send-stamp.md) 흐름 재사용(친구 선택 단계 생략). |

## AC

- 친구 목록 항목 탭 시 F-53, `토마토 보내기` 탭 시 [send-stamp.md](send-stamp.md) F-21로 이동한다.

## Open Questions

- 친구 추가 방식(링크/QR/아이디 검색)과 친구 수락 필요 여부.
- 칭찬판(스티커 형태로 보이는 토마토, F-53)의 공개/비공개 노출 범위는 아직 미정이며 곧 정의될 예정. 현재까지 논의된 공개/비공개는 홈 화면의 토마토 박스 기준이라 칭찬판에도 동일하게 적용되는지 별도 확인 필요 ([mypage-settings.md](mypage-settings.md) F-42 참고).
