# 친구

IA: 친구 → 검색 → 친구 추가 → 친구 목록 → 친구 칭찬판 → 친구 도장찍기
Figma 섹션: 친구
하단 탭: Friend 선택 상태.

| ID | 기능 | 설명 |
|---|---|---|
| F-50 | 친구 검색 | 친구 탭 상단 `친구 이름 검색` 입력창. 입력창을 누르면 검색 화면(`이름 검색` 입력 + 지우기 X + `취소` 버튼)으로 바뀌고 아래에 `추천 친구` 목록이 보인다. |
| F-51 | 친구 추가 | 친구 탭의 `+ 친구 추가하기`(검정 버튼)를 누르면 F-50 검색 화면으로 이동한다. `추천 친구` 목록과 검색 결과의 각 행에 `친구 추가` 버튼이 있고, 추가하면 버튼이 빨간 `친구` 표시로 바뀐다. 행에는 닉네임과 `@아이디`가 보인다. 추가하면 수락 절차 없이 바로 친구가 된다. 친구 칭찬판(F-53)의 `친구 추가하기` 버튼으로도 추가할 수 있다. |
| F-52 | 친구 목록 | "친구 목록" 제목 아래 친구 프로필/이름과 토마토 아이콘 + 나와 주고받은 토마토 수(예: 16개, 숫자는 달라진다)를 스크롤로 전체 노출(별도 `전체보기` 버튼 없음). |
| F-53 | 친구 칭찬판 | 뒤로가기, 친구 프로필 사진, 이름, `@아이디`. 친구가 아닌 사람이면 빨간 `친구 추가하기` 버튼, 친구면 `나와 주고 받은 토마토 N개` + 검정 `토마토 보내기` 버튼. 이어서 "상자 속 전체 토마토 N개"(N은 강조색 배지)와 상자 안 도장 격자, 많이 받은 칭찬, 나와의 토마토 기록(보낸/받은, 일시) + `전체보기`, 배지 컬렉션 + `전체보기`. 친구의 공개 범위 설정에 따라 노출 제한. |
| F-54 | 친구 도장찍기 | 친구 칭찬판에서 곧바로 도장 보내기. [send-stamp.md](send-stamp.md) 흐름 재사용(친구 선택 단계 생략). |

## AC

- 친구 목록 항목 탭 시 친구 칭찬판(F-53)으로 이동한다.
- 친구 추가 후 `추천 친구` 행의 버튼은 `친구`로 바뀐다.
- 친구 칭찬판의 `토마토 보내기` 탭 시 [send-stamp.md](send-stamp.md) F-21로 이동한다.
